# 우리사이 — 회기동 대학상권 매칭 플랫폼

학생의 **남은 시간과 지금의 용무**를 받아, 그 조건에 맞는 **회기 안의 답**을 붙여주는 AI 매칭 플랫폼.

---

## 실행

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

→ http://127.0.0.1:8000

## AI 모델 3개

| 모델 | 역할 | 실행 시점 | GPU |
|---|---|---|---|
| **EXAONE 3.5** | 자연어→조건 파싱, 리포트 작성, 후기 분류·요약 | 실시간 | 필요 |
| **Chronos-Bolt** | 시간대별 혼잡도 예측 | 배치 (하루 4~6회) | 불필요 (CPU 가능) |
| **BGE-M3** | 상인 과제 ↔ 학생 프로필 매칭 | 등록 시 1회 (벡터 캐싱) | 사실상 불필요 |

### AI를 쓰지 않는 부분

정확도가 생명인 계산은 모델이 아니라 `app/logic.py`에서 처리한다.

- 친구 시간표 교집합 — 저장된 표끼리 비교만 하면 됨
- 거리·시간 필터 — `왕복시간 + 체류시간 ≤ 남은시간`
- 단체예약 조건 매칭 — 조합 최적화
- 스탬프 카운트

## 실제 모델 연결하기

`app/ai.py` 상단의 플래그만 바꾸면 된다. 호출하는 쪽 코드는 전혀 손대지 않는다.

```python
USE_STUB = False   # True 이면 모델 없이 가짜 응답으로 UI만 동작
```

```bash
pip install torch transformers chronos-forecasting FlagEmbedding
```

> 현재는 `USE_STUB = True` 상태다. 규칙 기반 임시 응답이라 실제 모델보다 정확도가 낮다.
> 특히 프로젝트 매칭 유사도는 토큰 겹침으로만 계산하므로, BGE-M3를 붙이기 전에는 결과를 신뢰하면 안 된다.

## 예측 공식

```
최종 예측(t) = Chronos-Bolt 원본 예측(t) × 보정계수(t)
보정계수(t) = 1 + Σ(i=1..N) δ_i(t)        # N = 상권에 영향 주는 주체 수
```

회기동은 N=3 (경희대·한국외대·한예종). 두 대학이 동시에 시험기간이면 δ가 더해져 계수가 자동으로 커진다.
다른 지역으로 확장할 때는 N과 δ만 그 지역 데이터로 교체하면 같은 공식이 그대로 작동한다.

### 계수 근거

| 계수 | 값 | 근거 |
|---|---|---|
| 방학 | **0.91** | 실측 — 회기동 유동인구 −9.5% (1·3분기 vs 2·4분기) |
| 시험기간 | 미정 | 파일럿 중 점주 리포트로 확정 |
| 이벤트 | 미정 | 파일럿 중 확정 |

### 개선 방식

모델을 재학습하지 않는다. 점주의 일일 응답(한산/보통/붐빔)을 실측값으로 삼아
관측 배수를 계산하고, **지수평활**로 계수만 조정한다 (캘리브레이션).

목표: 베이스라인(요일별 단순 평균) 대비 **MAE 15% 이상 개선**
