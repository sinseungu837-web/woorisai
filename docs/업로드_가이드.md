# 처음 올리는 사람을 위한 단계별 가이드

GitHub과 LinkedIn은 목적이 다릅니다. 순서대로 하면 됩니다.

- **GitHub** = 코드를 저장·증명하는 곳 (개발자·면접관이 봄)
- **LinkedIn** = 사람에게 이야기로 알리는 곳 (인맥·채용담당이 봄)

먼저 GitHub에 올리고, 그다음 LinkedIn에 글을 씁니다.

---

# 파트 1. GitHub에 코드 올리기 (비공개)

## 준비: 이 두 개가 컴퓨터에 있어야 합니다

1. **GitHub 계정** — https://github.com 에서 가입 (무료)
2. **Git 프로그램** — https://git-scm.com/download/win 에서 받아 설치
   (설치 중 선택지는 전부 기본값 Next로 넘기면 됩니다)

설치 확인: PowerShell을 열고 아래를 입력해 버전이 나오면 성공.

```bash
git --version
```

## 1단계. GitHub에서 빈 저장소(repository) 만들기

1. github.com 로그인 → 오른쪽 위 **`+`** → **New repository**
2. **Repository name**: `woorisai` (영문·소문자 권장)
3. **Description**: `AICOSS 해커톤 대상 - 회기동 대학상권 매칭 플랫폼`
4. 공개 범위: **Private** 선택 ← 지금은 비공개
5. 아래 "Add a README" 같은 체크박스는 **전부 비워두세요** (이미 우리가 README를 만들어 둠)
6. **Create repository** 클릭

만들면 화면에 주소가 나옵니다. 예: `https://github.com/내아이디/woorisai.git`
이 주소를 복사해 두세요.

## 2단계. 내 컴퓨터에서 첫 설정 (최초 1회만)

PowerShell을 열고, 이름·이메일을 등록합니다(누가 올렸는지 기록용).

```bash
git config --global user.name "본인 이름"
git config --global user.email "본인 GitHub 이메일"
```

## 3단계. 프로젝트 폴더를 저장소로 만들어 올리기

PowerShell에서 아래를 **한 줄씩** 실행합니다.
(맨 앞 `cd` 는 프로젝트 폴더로 이동하는 명령입니다.)

```bash
cd "C:\Users\sinse\OneDrive\문서\claude\woorisai"
```

```bash
git init
```

```bash
git add .
```

여기서 무엇이 올라갈지 한번 확인하는 게 안전합니다.

```bash
git status
```

→ `.env`, `__pycache__`, `*.log` 같은 게 **안 보이면** 정상입니다
(우리가 만든 `.gitignore`가 걸러줍니다).
혹시 이런 게 보이면 멈추고 알려주세요.

이어서 커밋(저장 시점 만들기)과 업로드:

```bash
git commit -m "우리사이: AICOSS 해커톤 대상 프로젝트"
```

```bash
git branch -M main
```

```bash
git remote add origin https://github.com/내아이디/woorisai.git
```

(위 주소는 1단계에서 복사한 **본인 것**으로 바꾸세요)

```bash
git push -u origin main
```

→ 처음 push 하면 GitHub 로그인 창이 뜹니다.
   **"Sign in with your browser"**를 누르면 브라우저에서 로그인 → 자동 연결됩니다.

## 4단계. 확인

github.com 의 내 저장소 페이지를 새로고침 하면
README가 예쁘게 렌더링되고 파일들이 올라와 있습니다. 끝.

## (선택) 나중에 코드를 고쳤을 때

```bash
git add .
git commit -m "무엇을 바꿨는지 한 줄"
git push
```

# 파트 2. 시연 영상 + 발표 PPT를 README에 넣기 (선택, 강력 추천)

## 2-1. 플랫폼 시연 영상 (README에서 바로 재생됨)

GitHub README는 영상을 직접 재생할 수 있습니다. 방법:

1. github.com 내 저장소 → **Issues** 탭 → **New issue**
2. 제목 아무거나 입력하고, 본문 칸에 **시연 영상 mp4 파일을 드래그**
3. 잠시 뒤 `https://github.com/.../assets/....mp4` 같은 링크가 자동 생성됩니다
4. 그 링크를 복사 → 이 이슈는 **저장하지 말고 닫으세요**(Close, 링크는 살아 있음)
5. `README.md` 의 `## What it does` 위에 아래처럼 붙여넣기:

```markdown
## Demo

https://github.com/.../assets/....mp4
```

6. 저장 후 다시 push (`git add .` → `git commit` → `git push`)

> 영상 파일(약 7.5MB)은 이 방식이 깔끔합니다.
> 저장소에 직접 커밋하면 용량이 커지니 위 방법을 권합니다.

## 2-2. 발표 PPT (자료로 함께 보관)

PPT는 README에서 재생되진 않지만, 파일로 넣어두면 면접관이 내려받아 볼 수 있습니다.

1. 발표 PPT를 프로젝트 안 `docs/` 폴더에 복사
   (예: `docs/우리사이_발표.pdf` — **PDF로 저장하는 걸 권장**, 어디서나 열림)
2. `git add .` → `git commit -m "발표 자료 추가"` → `git push`
3. README 아래쪽에 링크 한 줄 추가하면 더 좋습니다:

```markdown
## Presentation

발표 자료: [docs/우리사이_발표.pdf](docs/우리사이_발표.pdf)
```

> PPT를 PDF로: 파워포인트 **파일 → 다른 이름으로 저장 → 파일 형식 PDF**.
> mp4가 박힌 원본 PPTX는 용량이 크니, 코드 저장소에는 **PDF만** 넣는 걸 권합니다.

# 파트 3. LinkedIn에 글 올리기 (한국어)

## 준비

1. **LinkedIn 계정** — https://linkedin.com 에서 가입
2. 프로필에 사진·학교·전공 정도는 채워두세요 (글 눌러본 사람이 프로필도 봅니다)

## 1단계. 글쓰기 시작

1. linkedin.com 로그인 → 홈 화면 맨 위 **"게시물 작성" / "Start a post"** 클릭
2. `docs/LINKEDIN_한국어.md` 의 **본문**을 복사해 붙여넣기
3. `[팀원 이름/태그]` 자리를 실제 팀원으로 바꾸기
   (`@`를 치면 그 사람 계정을 태그할 수 있습니다)

## 2단계. 영상/이미지 첨부

- 글쓰기 창 아래 **사진/동영상 아이콘** 클릭
- **발표 영상**을 올리는 게 가장 효과적입니다
  (영상이 부담되면 아키텍처 이미지 `docs/architecture.png` 한 장이라도)

## 3단계. 올리기

- 오른쪽 아래 **게시 / Post** 클릭
- 올린 직후 팀원·지인에게 좋아요·댓글을 부탁하세요
  (첫 1시간 반응이 확산에 크게 영향)

## 주의

- **비공개 GitHub 링크는 넣지 마세요.** 남이 눌러도 안 열립니다.
  코드를 보여주고 싶으면 GitHub를 Public으로 바꾼 뒤 링크를 다세요.

# 파트 4. 나중에 공개로 바꾸고 싶을 때

1. github.com 저장소 → **Settings**
2. 맨 아래 **Danger Zone** → **Change visibility** → **Make public**
3. 확인 문구 입력 후 전환
4. 공개 전 반드시 다시 점검:
   - `data/users.json` 에 실명·개인정보가 없는지
   - 커밋 기록에 실수로 올라간 키가 없는지
   (필요하면 저에게 "공개 전 점검"이라고 하시면 다시 훑어드립니다)
5. 공개 후 그 링크를 LinkedIn 글 **댓글**에 추가하면 됩니다.
